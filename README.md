# Freezenstein 3D

Freezenstein 3D is an independent open-source **game-data replacement project** for Wolfenstein 3D v1.4 full (`.WL6`). It provides original maps, art, audio, and story while remaining compatible with existing Wolf3D-compatible engines and requiring no Freezenstein-specific gameplay code.

## Is it Wolfenstein 3D?

**No.** Freezenstein is a distinct game inspired by the Freedoom model: same technical grammar, new creative expression.

## Does it contain commercial Wolf3D assets?

**No.** The repository will never ship commercial Wolfenstein 3D data. Compatibility documentation names baseline slots only.

## Difference from an engine/source port

Freezenstein is primarily **data**. Engines are consumers. Standalone releases may bundle a redistributable compatible engine under its own license.
